# まぶ鯖 公式サイト

Discordコミュニティ「まぶ鯖」の公式サイトです。

- サイト本体: `index.html`（単一ファイル、画像などのアセットは埋め込み済み）
- 招待リンク: https://discord.gg/GKkW4wCAVp
- カスタムドメイン: `CNAME` に `mabusaba.com` を設定

## 公開（GitHub Pages）

1. GitHub のこのリポジトリで **Settings → Pages** を開く
2. **Build and deployment** の Source を **Deploy from a branch** にする
3. Branch に **main / (root)** を選んで保存する

DNS 側でドメインを GitHub Pages に向ければ、`https://mabusaba.com` で公開されます。
